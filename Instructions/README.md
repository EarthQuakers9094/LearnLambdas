# Week 8 — Lambdas and Command Simulator

This is an independent Java teaching project. It does not require the Week 7 robot simulator.

1. Complete `Runnable.java` and `DoubleSupplier.java` first.
2. Work through `CLASSWORK8.md` with Scho.
3. Finish `HOMEWORK8.md` independently.

The provided starter files compile but intentionally contain TODOs; the commands and bindings will not all work until you implement them.

From this directory:

```bash
javac *.java
java LambdaDemo
java ControllerDemo
```

**Note:** These project-local `Runnable` and `DoubleSupplier` interfaces are teaching copies. They are not Java's built-in versions and should be removed when converting to a WPILib project.

`runToCompletion()` is a blocking educational helper, not the WPILib scheduler. No threads are required.
